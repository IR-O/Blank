# 🎵 Chizuru Music Bot

Telegram Voice Chat Music Player with Queue Management

## ✨ Features

- 🎧 Play high-quality audio
- 🎥 Play video in voice chat
- 📋 Advanced queue management
- ⏯️ Pause, Resume, Skip
- 🎨 Beautiful thumbnails
- 📊 Real-time stats
- 🔄 Auto-play next song

## 📝 Commands

| Command | Description |
|---------|-------------|
| `/play` | Play audio |
| `/vplay` | Play video |
| `/skip` | Skip song |
| `/pause` | Pause |
| `/resume` | Resume |
| `/stop` | Stop |
| `/queue` | Show queue |
| `/volume` | Change volume |
